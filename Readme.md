Hospital Management System (HMS)

This project is a web-based Hospital Management System developed as part of the Modern Application Development II course. It enables efficient management of hospital operations by allowing Admins, Doctors, and Patients to interact through a unified platform. The system supports core functionalities such as user authentication with role-based access, appointment booking and management, and maintaining patient treatment history.

The application is built using Flask and Flask-RESTful for the backend, Vue.js and Bootstrap for the frontend, and SQLite as the database. Additionally, Redis and Celery are used for implementing background jobs such as daily reminders, monthly reports, and CSV export of patient data.

Overall, the system aims to simplify hospital workflows, reduce manual effort, and provide a structured way to manage patient care and medical records.
